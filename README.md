# Daily Memo Lite

A tiny memo pad I built while practicing plain HTML, CSS and JavaScript.

## What it does

- add, edit and delete notes
- search by title, body or tag
- keep everything in the browser with `localStorage`
- install it to the home screen and use it offline

## Notes to self

- `justify-content` works on the main axis; `align-items` works on the cross axis.
- `gap` is usually cleaner than adding margins between cards.
- `-webkit-line-clamp` needs `display: -webkit-box` to work.
- Keep the JavaScript in one file; fewer moving parts.

## Run it

Open `index.html` in a browser, or serve the folder with any static file server.

No build step, no dependencies.
